Integration-first engineering

Do not duplicate a database when an interface will do.

RecoveryFlow demonstrates this approach directly. The NHS source system remains authoritative for patients, waiting lists and appointments; Vermalio receives only what is needed to run one capacity-recovery transaction and returns the result.

Design objective: minimise migration, duplicate records, supplier lock-in and unnecessary sensitive-data handling while still automating the operational work between systems.
